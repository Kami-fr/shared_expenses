# ADR-003 - Coding Style

## Status

Accepted

## Context

The project needs consistent coding conventions to remain maintainable.

## Decision

Shared Expenses follows Home Assistant coding conventions whenever possible.

Project-specific rules are documented in `docs/coding_guidelines.md`.

Examples:

- Single-line function signatures whenever possible.
- English comments and docstrings.
- Type hints everywhere.
- Small files.
- One class = one responsibility.

## Consequences

- Consistent code.
- Easier reviews.
- Easier maintenance.
